# Installing RelayMail

RelayMail is a fork of Thunderbird for Android. It can be installed alongside the original Thunderbird app.

## Option 1: Obtainium (Recommended)

[Obtainium](https://github.com/ImranR98/Obtainium) keeps the app updated automatically by checking GitHub Releases.

1. Install Obtainium from [F-Droid](https://f-droid.org/packages/dev.imranr.obtainium.fdroid/) or [GitHub](https://github.com/ImranR98/Obtainium/releases)
2. Open Obtainium and tap **Add App**
3. Enter the source URL: `https://github.com/thoomi/relaymail`
4. Tap **Add**
5. Tap **Install**

Obtainium will notify you when new releases are available.

## Option 2: Manual Install

1. Go to [Releases](https://github.com/thoomi/relaymail/releases)
2. Download the `.apk` file from the latest release
3. Open the downloaded file on your Android device and follow the prompts

You may need to allow installation from unknown sources in your device settings.
